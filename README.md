# SVG 色バリエーションスタジオ

SVGロゴの色候補を安全に比較し、PNG素材も背景付きで確認・出力するためのGitHub Pages向け静的Webツールです。

## 目的

元SVGのベクター構造を壊さずに、塗り、線、線幅、背景を調整します。PNGやPNG埋め込みSVGはラスタ素材として読み込み、背景確認とPNG出力に使えます。ロゴの色確認、候補ボード作成、引き継ぎ用出力に使うツールで、ピクセル単位のペイントツールではありません。

## 機能

- 初期表示で `speedad-login-header-logo.svg` を読み込みます。
- 塗り、線、線幅、確認用背景を変更できます。
- PNGファイルと、安全な `data:image/png` 埋め込みSVGをラスタ素材として読み込めます。
- 現在色と候補カードに、背景に対するロゴ視認性の補助判定を表示できます。
- プレビュークリックまたはパーツ一覧からSVGパーツを選択し、部分塗りを確認できます。
- 複数サブパスを持つ `path` は「詳細分割」で見た目上の小パーツ単位に分けて色を確認できます。
- 候補ボードで名前、メモ、ステータス、HEXカラーを管理できます。
- ベクターSVGはCanvas再トレースやPNG埋め込みなしでSVGを出力します。
- Canvasを描画先としてのみ使い、ベクターSVGとラスタ素材の2x/4x PNGを出力します。
- インラインSVG、CSS変数、視認性判定付きパレットJSONをコピーできます。
- ラスタ素材ではSVG/inline SVG/CSS変数出力を無効化し、ベクター編集対象ではないことを明示します。
- 安全でないSVG要素や属性、外部参照、ベクターとラスタが混在するSVGを拒否します。
- CDN依存なしの静的ファイルだけで動作します。

## ローカル利用

`index.html` を直接開くか、GitHub Pagesと同じ取得経路で確認するためにローカル静的サーバーを起動します。

```powershell
python -m http.server 4173
```

その後、`http://127.0.0.1:4173/` を開きます。

## GitHub Pages

`main` ブランチのルートを公開元にしてください。`.nojekyll` を含めているため、GitHub Pagesは静的アセットをそのまま配信します。

## ソース要件

ベクター編集に使うソースSVGは、ラスタ画像の `<image>` 要素を含まないことを前提にしています。内蔵ソースは次の構造です。

- `viewBox="0 0 1134 991"`
- `<path>` 要素 4件
- 詳細分割候補 28件
- `role="img"`
- `aria-label="SPEED AD ヘッダーロゴ"`
- `fill-rule="evenodd"`

PNGファイルと、`<image href="data:image/png;base64,...">` だけで構成されたSVGはラスタ素材として読み込めます。ラスタ素材はパーツ一覧、詳細分割、部分塗り、SVG/inline SVG/CSS変数出力の対象外です。

## スコープ

パーツ選択式の部分塗り、`path` 内サブパスの詳細分割、ロゴ視認性の補助判定、PNG/ラスタSVGの背景確認とPNG出力に対応しています。本格的なバケツ塗り、閉領域の自動検出、PNGの自動ベクター化、任意位置でのパス切断、ブラシ、消しゴム、ベジェ曲線・パス形状編集、法的なアクセシビリティ適合保証、サーバー保存、認証、共同編集は対象外です。
